# 👻 Ghost Planet

Ghost Planet is a paranormal investigation platform for organizing sightings, investigations, and field evidence.

### Project Status

This project is still early in development.

### Features

Ghost Planet is being built to support:

- Paranormal sighting reports
- Investigation management
- Field evidence organization
- Investigation notes and observations
- Location-based paranormal activity

More features will be added as development continues.
